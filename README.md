# Список покупок

Простая консольная программа на Python: добавляет товары, показывает список и удаляет их.
Используется только стандартная библиотека — ничего устанавливать не нужно.

## Запуск

```bash
python main.py
```

Дальше программа сама покажет меню:

```
===== СПИСОК ПОКУПОК =====
  1. Добавить товар
  2. Показать список
  3. Удалить товар
  0. Выход
```

Введите номер пункта и нажмите Enter.

## Где хранится список

Товары сохраняются в файл `shopping_list.json` в той же папке.
Файл создаётся автоматически при первом добавлении.
Его можно открыть в любом текстовом редакторе — это обычный текст в формате JSON.

## Пример

```
Выберите действие: 1
Что добавить: Молоко
Добавлено: Молоко

Выберите действие: 2

Ваш список:
  1. Молоко

Выберите действие: 3

Ваш список:
  1. Молоко
Номер товара для удаления: 1
Удалено: Молоко
```
